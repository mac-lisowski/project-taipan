# Memory index

Long-term agent memory for this repo. AGENTS.md holds the rules;
this dir holds what the agent learned while working.

## Files

- `current.md`: active work, blockers, next step. Read first.
- `decisions.md`: why things are the way they are. Append-only.
- `learnings.md`: durable lessons, gotchas, user preferences.

## Rules for the agent

- Read `current.md` before starting a task.
- Update `current.md` when work pauses or finishes.
- Log a decision in `decisions.md` when a non-obvious choice is made.
- Log a lesson in `learnings.md` when the user corrects you or
  something breaks in a surprising way.
- Keep entries short. One fact per line. No prose.
