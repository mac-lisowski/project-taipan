Chat surface

OpenUI AgentInterface at /chat. Threads persist in the API. Light and dark themes, always in sync. This page is a map. Read spec.md for the full text.

Module shape

The browser holds no provider key. The BFF relays. The API owns threads, persistence, and the gateway call.

flowchart LR
  U["Browser: AgentInterface at /chat"] -->|"POST /api/chat, session cookie"| BFF1["BFF chat proxy: stream relay, long timeout"]
  U -->|"/api/threads CRUD"| BFF2["BFF threads proxy"]
  BFF1 --> API1["API chat router: validate, replace history, stream"]
  BFF2 --> API2["API threads router: restStorage contract"]
  API1 -->|"OpenAI SSE"| GW["LiteLLM gateway"]
  API1 --> DB[(Postgres)]
  API2 --> DB

Test seams
