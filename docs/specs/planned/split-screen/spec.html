Split screen

One AgentInterface owns the screen. A rest-slot child becomes a resizable right pane: an app view, or a second independent chat. State rides the ?pane= param. Read spec.md for the full text.

Layout shape

The pane is a flex sibling inside the SDK root container. It never remounts on navigation. The chat kind mounts a nested interface with its own provider.

Test seam

All logic sits in one pure module. Vitest covers it with stubbed window and local storage, matching the sidebar-state suite. No DOM tests, no HTTP tests.
