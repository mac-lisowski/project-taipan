One object seam, bytes out of Postgres

Visual companion to spec.md. A storage package owns object bytes; the api owns file rows and the proxy endpoints; MinIO is dev, Railway/AWS S3 is prod.

The seam: ObjectStore port, two adapters

Config builds the S3 adapter; tests swap app.state for the fake. Callers never see a vendor client.

Where each byte lives

Postgres: files row

  • id uuid pk, tenant_id, scope user|tenant
  • created_by_user_id null, RESTRICT (attribution)
  • purpose, bucket, object_key (unique)
  • filename, content_type, size_bytes, sha256

S3: immutable object

  • key = purpose-prefix/tenant_id/file_uuid
  • one bucket, purpose prefixes (attachments/, artifacts/)
  • user-scope dies with user; tenant-scope while tenant lives
  • object then row then commit; failure deletes the object

Tests cross the port only. No test stubs the minio SDK itself.

Deferred on purpose

Presigned URLs, dedup, quotas, GC sweep, encryption at rest, public reads. The proxy path costs Railway service egress on uploads; presigned PUT is the documented follow-up once a real consumer needs it.
