Field encryption capability

Implements ADR-0001. Capability only: no model field changes. Companion: docs/specs/implemented/field-encryption/spec.md.

One new seam: the crypto package. Everything behind it is injected. The ORM adapter is a delegate, not a second brain.

Test seam: what tests cross

  • Unit: stub Cipher + DekStore + DekCache. Assert tenant-bound decrypt (AAD), the put race, missing-DEK errors, strict envelope grammar, round-trip, tamper failure, resolver fallback, single-flight unwrap, cache hits.
  • ORM: in-memory database + stubbed crypto module. Assert column round-trip, error outside tenant scope, mixed-scope flush detection.
  • Live: real Infisical, KMS test conventions, skip when down. Round-trip and cache behavior through the real adapters.

No test crosses FastAPI or HTTP. Routers never learn encryption exists.

Not here

No encrypted field yet, no tenants table, no request middleware, no blind indexes, no repository deletion. Tenancy substitutes only the resolver. The first real encrypted field is a later feature.
