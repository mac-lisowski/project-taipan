Prototype lives in .scratch/ or is deleted. Mechanical DoD check: ADR exists, names both options, states criteria, cites the prototype outcome, answers the repository question.

Why a spec for a decision

The wrong outcome is not "pick A over B". It is letting the feature spec improvise the seam mid-implementation and stranding a shallow repository layer or a scattered encryption concern.
